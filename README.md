# Mururu Blink & LipSync

ムルルに、まばたき機能と声に合わせて口が動くリップシンク機能を追加するUnityツールです。Modular Avatarで非破壊に組み込みます。

## ダウンロード・使い方

- [BOOTH](https://unlibra.booth.pm/items/9056145) / [GitHub Releases](https://github.com/unlibra/mururu-blink-lipsync/releases)：配布用のunitypackage
- [VCC配布一覧](https://docs.unlibra.com/vpm/)：登録後、使用するプロジェクトのManage Packagesから追加
- [マニュアル](https://docs.unlibra.com/mururu-blink-lipsync/)：導入・設定・更新・削除の手順
- [変更履歴](CHANGELOG.md)

## 対応環境

| 項目 | バージョン |
|---|---|
| Unity | 2022.3 |
| VRChat SDK Avatars | 3.10.x |
| Modular Avatar | 1.18.x 以降（NDMFを含む） |
| 対応アバター | Mururu（ver2.2.2で確認） |

## ソースコード・開発資料

製品コードは `Editor/` と `Runtime/`、自動テストは `Tests/Editor/` にあります。実装の仕組みやテストの実行方法などは[開発資料の案内](Documentation~/README.md)を参照してください。
