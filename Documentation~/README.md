# 資料の案内

利用者向けの使い方は[ドキュメントサイト](https://docs.unlibra.com/mururu-blink-lipsync/)を参照してください。このフォルダはUnityの取り込み対象外です。

| 場所 | 内容 |
| --- | --- |
| [website/](website/) | 公開マニュアル・画像（VitePress） |
| [booth/](booth/) | 公開用の商品画像 |
| [maintenance/MOUTH_RETURN.md](maintenance/MOUTH_RETURN.md) | 口復帰の仕組み・対応範囲 |
| [maintenance/TEST_ENVIRONMENT.md](maintenance/TEST_ENVIRONMENT.md) | テスト環境に必要なアセットと実行方法 |
| [maintenance/PUBLICATION.md](maintenance/PUBLICATION.md) | 公開ファイルの管理・個人情報の混入防止 |
| [maintenance/WEBSITE.md](maintenance/WEBSITE.md) | GitHub Pages配信・IndexNow・サイト監視 |
| [maintenance/RELEASE.md](maintenance/RELEASE.md) | CIでのunitypackage生成・GitHub Releases公開・BOOTHへの登録 |
| [Run-Tests.ps1](Run-Tests.ps1) | 製品・全テストを外部Unityプロジェクトへ同期し、Unity CLIで実行 |

現在の仕様と制約は `maintenance/`、利用者への変更履歴はルートの[CHANGELOG](../CHANGELOG.md)へ記載します。編集原稿、販売方針、個人環境の設定、研究ログはリポジトリの外で管理します。
