## できること

### 自然なリップシンク

マイクの声に合わせて会話中だけ自然に口が動き、黙ると元の口に戻ります。
表情改変やハンドサインで作った表情を維持したまま、自然な発話表現を実現できます。

### まばたきの追加

フェイトラのない環境ではムルルが自動的にまばたきします。
SelfieExpressionを使うと、自分のまばたきがムルルに反映されます。
ムルルがもっと生き生きします。

### ジェスチャー別の柔軟な設定

「ピースのときは目が &gt;&lt; になるからまばたきさせたくない」など、ハンドサインやFacial EXごとに、まばたきとリップシンクを止めるか選べます。

### 非破壊・ワンボタン導入

インストールボタンひとつで導入できます。
Bodyのメッシュや既存のFX・メニュー・パラメータは書き換えず、アンインストールで導入前に戻せます。
