# 対応環境

| 項目 | バージョン |
|---|---|
| Unity | 2022.3 |
| VRChat SDK Avatars | 3.10.x |
| Modular Avatar | 1.18.x 以降 |
| 対応アバター | ムルル ver2.2.2 |

- NDMF は Modular Avatar と一緒に導入されます。
- MururuChild など別体型のムルルには対応していません。
- 口周辺のメッシュを改変したBodyでは導入できないことがあります。
- SelfieExpressionはまばたきの動作確認済みです。ミュート状態での口の動きには対応していません。
- OSC Eye Tracking形式のまばたきには仕様上は対応を想定していますが、実機動作は未検証です。
- VRCFaceTrackingは仕様上は対応していない可能性が高いです。
