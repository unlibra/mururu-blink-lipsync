# FAQ

## インストールボタンが押せない

「対象アバター」は選択されていますか？Hierarchyでシーンに置いたムルルを選択するか、「対象アバター」にドラッグしてください。Playモード中は操作できません。

## Prefab Variantでも使える？ {#prefab-variant}

はい。親Prefabに保存した導入内容をVariantでも引き継ぎます。

- **親にインストールしてからVariantを作る場合**：導入内容を親Prefabに保存してあれば、Variantごとの追加インストールは不要です。
- **Variantを作った後で親にインストールする場合**：後から親Prefabに導入内容を保存すると、既存のVariantにも継承されます。ただし、Variant側でOverrideしている項目は、その値が優先されます。

シーン上の親インスタンスにインストールしただけでは、親Prefab自体には反映されません。そのインスタンスからVariantを作ると、導入内容は作成したVariantに保存されます。

Variantごとに設定を変える場合は、そのVariantをシーンに置いてツールから設定を変更し、変更内容をそのVariantに保存してください。個別の変更を共通の親へApplyすると、ほかのVariantにも影響します。

## 親をアンインストールしてもVariantに残る {#prefab-variant-uninstall}

シーン上の親からアンインストールしても、保存済みのPrefabやVariantは自動では変更されません。シーンを保存することと、Prefabへ変更を保存することも別です。

- **親Prefabから継承した導入**：導入元の親PrefabをPrefabモードで開き、ツールでアンインストールして保存すると、継承先のVariantからも外れます。
- **Variant自身に保存した導入**：親から外しても残ります。そのVariantをPrefabモードで開き、ツールでアンインストールして保存してください。

ツール本体を削除する前に、使っているScene・Prefab・Variantから導入内容を外して保存してください。導入内容を残したまま本体を削除すると、残ったコンポーネントのスクリプト参照が失われ、Missingになります。

ほかのSceneやPrefabが参照している生成ファイルは、アンインストール時に削除せず保持します。

## ムルルのアバターがピンクになっている

プロジェクトにlilToonを追加してください。ムルルはlilToonを使っているため、別に追加する必要があります。

lilToonは[こちら](https://lilxyzw.github.io/lilToon/ja_JP/)です。

::: tip
lilToonは、VCCのManage Packagesから使用するプロジェクトに追加してください。
:::

## Unityでリップシンク用の口が表示されない

Unityの編集画面では、常に元の表情の口が表示されます。リップシンク用の口は、VRChatで話している間だけ表示されます。言葉の切れ目で口がちらつかないよう、声が途切れてもすぐには切り替えず、短い待ち時間を設けています。

Unity上でリップシンク用の口を確認したいときは、BlendShapeの値を次のように変えてください。

| オブジェクト | BlendShape | 値 |
|---|---|---|
| Body | `mouth_off` | 100 |
| MururuBlinkLipSync > LipSync_Mouth | `SE_hide_self` | 0 |
| MururuBlinkLipSync > LipSync_Mouth | `SE_mouth_A`・`SE_mouth_I`・`SE_mouth_U`・`SE_mouth_E`・`SE_mouth_O` | 合計が100以下になるように調整 |

確認が終わったら、`mouth_off` を0、`SE_hide_self` を100、AIUEOのBlendShapeを0に戻してください。

## リップシンク用の口の見た目が顔と違う

リップシンク用の口は、アップロード時にBodyのマテリアルやライティングの設定に自動で合わせます。Bodyのマテリアルを差し替えても、インストールし直す必要はありません。ただし、メニューやアニメーションで切り替えるマテリアルには追従しません。

## VRChatでリップシンクしない

マイクがミュートになっていないか、リップシンクを止める表情（LipSync のチェックを外した表情）になっていないか確認してください。

## 「滑らかな口の復帰を使えない条件があります」と表示される

ビルド時のNDMF警告に、滑らかな復帰を使えない表情・条件と理由を表示します。その範囲では全部または一部の組み合わせが瞬時切り替えになります。アップロードは継続できます。

口の形状を生成できない場合のほか、対応外の口シェイプが有効な場合や、FXから復帰先の口を確定できない場合に表示します。口に関係のない名前のシェイプでも、実際に口の頂点を動かしていれば判定の対象になります。設定でリップシンクを止めた表情については、警告を省きます。

## 喋ると出てくる音符を消したい

設定画面の **発話時の音符を非表示** にチェックを入れ、**設定の変更を適用** を押してからアップロードしてください。元のFXを書き換えずに音符を非表示にできます。チェックを外すと、元のFXの設定を使います。

手動で調整する場合は、`Mururu_FX`コントローラーの`Facial LipSync`レイヤーのウェイトを`0`にすると無効化されます。このレイヤーに音符以外の効果を追加している場合は、その効果も止まります。

## 「標準のMururuと異なる可能性があります」と表示される

別体型のムルルや、頭部・口周辺を改変したBody、FBXのScale設定を変更したBodyで表示されます。続行すると、VRChatで話したときに口がずれて表示されることがあります。問題があれば **アンインストール** で元に戻せます。

## 「mouth_Aから対応するAIUEO口頂点を特定できませんでした」と表示される

Bodyの口周辺のメッシュや `mouth_A` の変更、FBXの座標軸・スケールの違いで表示されます。口を編集していなくても、Blenderからの書き出しで座標軸が変わる場合があります。

「口の前方向: +Y（標準: +Z）」と表示される場合は、次の項目を確認してください。それ以外は、まず改変前のBodyで導入できるか確認してください。

## Bodyの座標軸が標準ムルルと異なる {#body-axis}

見た目が同じでも、FBX内部で口が動く方向が異なると、口を抽出できません。UnityのTransformの回転値だけを0にすると、見た目や骨の変形が変わるため、メッシュの座標も合わせて補正します。

以下は、エラーに **口の前方向: +Y（標準: +Z）** と表示されるモデルで確認した手順です。Blender 5.2.1 LTSの **FBX（Legacy）** で検証しています。他の軸や、FBX内にアニメーションを同梱したモデルは未検証です。

1. FBXとBlenderファイルをバックアップし、コピーで作業します。
2. Blenderで対象のFBXを読み込みます。オブジェクトモードで、口のシェイプキーがあるBodyだけを選択します。アーマチュアは選択しません。
3. Bodyの回転がXYZとも0°であることを確認します。異なる場合は、この手順をそのまま実行しないでください。トランスフォーム座標系は **グローバル** にします。
4. `R` → `X` → `90` → `Enter` で回転させます。
5. `Ctrl+A` → **回転** を実行します。
6. `R` → `X` → `-90` → `Enter` で見た目を元に戻します。最後の回転は適用しません。
7. Bodyとアーマチュアなど必要なオブジェクトを含め、別名のFBXへ書き出します。検証時の設定は次のとおりです。

| 設定 | 値 |
| --- | --- |
| Scale | 1 |
| Apply Scalings | FBX All |
| Forward / Up | -Z Forward / Y Up |
| Apply Unit / Use Space Transform | ON |
| Apply Transform / Apply Modifiers | OFF |
| Add Leaf Bones / Bake Animation | OFF |

Unityでコピーを読み込み、口の位置、AIUEO、既存の表情、頭・腕の動きを確認してから差し替えてください。確認したモデルでは、全7,043頂点・173シェイプと頭・腕の骨変形の差は最大約0.001mmで、口の抽出・生成も成功しました。

::: tip 対応範囲
この手順は座標軸による導入エラーへの対処です。補正後は、実際の口の構造とシェイプから表情ごとに滑らかな復帰が可能か判定します。口以外のBody改変だけで全体が無効にはなりません。対応できない表情だけ、無音から80ms後の瞬間切替になります。任意の口構造や表情Controllerへの対応を保証するものではありません。
:::

## 「Bodyの親がAvatar Rootか確認してください」と表示される

BodyをアバターのRoot直下に置いてください。

## 「Facial EXパラメータがExpression ParametersとMA Parametersに見つかりません」と表示される

MA Menu Itemなどで作られるパラメータの場合は、そのまま続行できます。名前が間違っている場合は、[詳細設定](./settings#詳細設定) でパラメータ名を確認してください。
