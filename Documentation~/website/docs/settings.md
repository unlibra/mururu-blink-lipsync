# 表情ごとの設定

ハンドサイン（左手・右手）とFacial EX（表情メニュー）のそれぞれで、まばたき（Blink）とリップシンク（LipSync）を有効にするか選べます。チェックを外した表情の間は、その機能が止まります。

![個別設定を開いた表情ごとの設定](/images/2.webp)

## 初期設定

| 入力 | Blink | LipSync | 理由 |
|---|---|---|---|
| Left Hand | 有効 | 有効 | ムルルの左手のハンドサインは口の表情のため、まばたきは止めない |
| Right Hand | 停止 | 有効 | ムルルの右手のハンドサインは目の表情のため、まばたきで崩れないよう止める |
| Facial EX 1〜8 | 停止 | 有効 | 目の表情を保つためまばたきを止める |

リップシンク用の口は話している間だけ表示されるため、リップシンクは初期設定ですべて有効です。黙っている間は表情の口がそのまま表示されます。

## 設定を変える

1. Left Hand・Right Hand・Facial EX の行のチェックで、まとめて切り替えます。ハンドサインやFacial EXの番号ごとに変えたいときは、**個別設定** を開きます。
2. **設定の変更を適用** を押します。押すまでアバターには反映されません。

初期設定に戻すには **デフォルト設定に戻す** を押します。確認のあと、そのまま適用されます。

## 止まったときの動き

- **Blink を止めた表情**: まばたきしません。目はアニメーションの表情のままになります。
- **LipSync を止めた表情**: 話していてもリップシンク用の口は表示されず、表情の口のままになります。話している途中でその表情に変えても、すぐに表情の口に戻ります。

## 発話時の音符を非表示

チェックを入れて **設定の変更を適用** を押すと、アップロード時に音符を非表示にします。インストール前に選ぶこともできます。初期設定はチェックなしです。チェックを外すと元のFXの設定を使うため、手動で音符を無効にしていた場合は、その設定を維持します。

標準ムルルの音符が対象です。元のFXやSceneの音符は書き換えません。`Facial LipSync`レイヤーに別の効果を追加している場合は、その効果も止まります。対象レイヤーが見つからないなど、特定できない場合はビルド時に警告し、元のFXを維持します。

## 詳細設定

### Facial EXパラメータ

Facial EXの切り替えに使っている Int 型のパラメータ名です。通常は自動で入るため、変える必要はありません。

表情メニューを改変していて自動で入らない場合は、**自動検出** を押すか、パラメータ名を入力してください。Expression Parameters と Modular Avatar の MA Parameters で定義したパラメータを検出できます。`GestureLeft` や `Voice` など、VRChatの組み込みパラメータは指定できません。
