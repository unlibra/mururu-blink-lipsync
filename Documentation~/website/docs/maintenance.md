# 更新・修復・アンインストール

## ツールを更新したとき

新しいバージョンのunitypackageをインポートしたあと、ウィンドウの案内に従ってください。更新や修復などの操作が必要な場合だけ案内が表示されます。ツールのバージョンは右上の **ヘルプ** で確認できます。

- 「設定の変更を適用」での更新案内が表示された場合は、**設定の変更を適用** を押します。
- **新しい方式に更新** ボタンが表示された場合は、それを押します。

## 修復

「生成ファイルへの参照が失われています」と表示されたときや、BodyをFBXから入れ直したときは、**修復** を押してください。設定はそのままで、必要なファイルを作り直します。

## アンインストール

ウィンドウで対象のアバターを選び、**アンインストール** を押します。追加したオブジェクトと生成ファイルを削除し、LipSyncとEye Lookの設定を導入前に戻します。

::: warning
アンインストールや設定の変更は、Ctrl+Z ではなくウィンドウのボタンで行ってください。Ctrl+Z で戻すと、削除済みの生成ファイルを参照する状態になることがあります。その場合は **修復** で直せます。
:::
